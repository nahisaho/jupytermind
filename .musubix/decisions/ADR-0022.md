# ADR-0022: Fixed ordered 12-system FCC slip-system table (Table CP-12) with explicit crystal-to-sample orientation rotation

## Context / 背景
REQ-AIMS-050 requires deterministic Schmid-factor and resolved-shear-stress
computation for the FCC {111}<110> slip-system family. Early drafts (a)
stated the wrong system count (8 instead of the correct 12-member family),
(b) left the sign convention of each system's Schmid factor undefined, and
(c) accepted a "crystal orientation" without defining its representation
or how it relates the crystal frame to the applied (sample-frame) stress
tensor — three issues each identified across separate rubber-duck review
rounds.

## Decision / 決定
DES-AIMS-050 hard-codes the full 12-member {111}<110> family as an exact
ordered list of (plane normal, slip direction) pairs (Table CP-12, given
in REQ-AIMS-050's Constraints), with crystal orientation represented as a
proper orthogonal 3x3 matrix Q mapping crystal-frame vectors to the sample
frame (`n_sample = Q @ n_crystal`, `d_sample = Q @ d_crystal`). The module
rejects a non-orthogonal or non-unit-determinant Q (checked within 1e-6)
and a non-symmetric or zero-norm stress tensor before any Schmid-factor
computation. The reference [100]-tension fixture uses Q = identity.

## Rejected alternatives / 却下した代替案
- Reporting only `abs(schmid_factor)` without a fixed sign convention:
  rejected because REQ-AIMS-050 also requires a signed resolved shear
  stress tau and a signed shear rate (via `sign(tau)`), which cannot be
  tested deterministically without pinning down each system's sign.
- Accepting orientation as unconstrained Euler angles or an unvalidated
  matrix: rejected because an invalid (non-orthogonal) matrix would
  silently distort the Schmid-tensor geometry rather than failing fast
  under REQ-AIMS-003.

## Consequences / 結果
Any future change to the slip-system enumeration order or sign convention
is a breaking change to this module's acceptance tests and must be
re-derived and re-validated against Table CP-12, not changed ad hoc.
