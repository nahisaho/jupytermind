# ADR-0028: RDKit as a required (not optional/pure-Python) SMILES/descriptor dependency

## Context / 背景
Every module in this skill (REQ-ACHEM-010 through 050) needs to parse
SMILES strings, compute standard molecular descriptors, and generate
Morgan fingerprints. The user was asked to choose between making RDKit a
required dependency (`require_rdkit`) versus implementing a pure-Python
fallback or treating RDKit as optional; the user chose `require_rdkit`.

## Decision / 決定
`rdkit` will be added to `pyproject.toml`'s `dependencies` list as a
required package during implementation (confirmed installable in this
repository's development `.venv`, version `2026.03.6` observed at the
time of this decision; not yet applied to `pyproject.toml` as of this
design decision — tracked as an implementation-phase task). DES-ACHEM-010's
`run_molecular_descriptors` (and every other module that needs SMILES
parsing or descriptors) calls `rdkit.Chem.MolFromSmiles` and
`rdkit.Chem.Descriptors`/`rdMolDescriptors` directly; there is no
pure-Python SMILES-parsing fallback path and no feature-flagged
degradation when RDKit is absent.

## Rejected alternatives / 却下した代替案
- A pure-Python SMILES parser/descriptor calculator: rejected as a far
  larger, error-prone undertaking than wrapping a mature, widely-used,
  BSD-licensed cheminformatics toolkit; RDKit's descriptor functions are
  the de facto reference implementation this requirements document's own
  acceptance fixtures were computed against (see REQ-ACHEM-010's aspirin
  values).
- Treating RDKit as an optional dependency with a degraded-functionality
  mode when absent: rejected because every module in this skill's first
  increment depends on RDKit for its core computation (SMILES parsing is
  not optional for any of the 5 modules); an "optional" dependency that is
  actually required by 100% of the skill's modules adds complexity
  (import-guard checks, a degraded error path) without a corresponding
  use case where RDKit is genuinely absent but the skill is still useful.

## Consequences / 結果
`ai-chemistry-scientist` cannot be imported/used in an environment without
RDKit installed; this is an accepted, explicit constraint (unlike
`ai-materials-scientist`, which uses only numpy/scipy/pandas/scikit-learn,
already universally present). CI/dev-environment setup must install
`rdkit` before this skill's tests can run.
