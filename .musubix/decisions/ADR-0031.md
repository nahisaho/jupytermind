# ADR-0031: Fully pinned 20-molecule bundled dataset with fixed Morgan-fingerprint configuration and tie-break rule

## Context / 背景
An initial REQ-ACHEM-040 draft specified "a bundled sample dataset of
exactly 20 named molecules" but pinned only 4 of the 20 rows (aspirin,
ibuprofen, caffeine, paracetamol), leaving the remaining 16 unspecified.
Rubber-duck review found this made the acceptance fixture
non-deterministic: the unpinned 16 rows could change top-`k` ranking
membership/order, and the Morgan fingerprint configuration (chirality/
feature invariants, exact API call) and `k`'s valid range were also
unspecified.

## Decision / 決定
REQ-ACHEM-040 now pins all 20 `name,smiles` rows, each independently
verified to parse via `Chem.MolFromSmiles`. Fingerprints use
`AllChem.GetMorganFingerprintAsBitVect(mol, radius=2, nBits=2048)` with
RDKit's default `useChirality=False`/`useFeatures=False` invariants (or
the equivalent non-deprecated `MorganGenerator` API producing identical
bit vectors), and Tanimoto similarity is explicitly `c / (a + b - c)`.
Ties are broken by ascending molecule `name`. `k` is constrained to an
integer in `[1, 20]`. The aspirin- and ibuprofen-query top-5 rankings were
empirically recomputed against the full pinned 20-molecule dataset (not
just the original 4) and are now the exact acceptance fixture, including
the `diclofenac`/`naproxen` exact-tie case (both `0.195652...` for an
aspirin query), resolved by the ascending-name rule.

## Rejected alternatives / 却下した代替案
- Pinning only the 4 originally-named molecules and leaving the rest
  "any 16 additional molecules": rejected because the acceptance
  criterion's claimed ranking (e.g., "paracetamol ranks immediately after
  aspirin") is not actually guaranteed once other, unpinned molecules can
  have higher similarity (empirically, `warfarin` ranks above
  `paracetamol` for an aspirin query once the full dataset is considered).
- Leaving fingerprint chirality/feature invariants and the Tanimoto
  formula implicit: rejected because RDKit supports multiple Morgan
  fingerprint configurations (useChirality, useFeatures, different
  generator APIs) that can produce different bit vectors and similarity
  values for the same molecule pair.
- No tie-break rule: rejected because `diclofenac` and `naproxen` are
  empirically tied (both `0.1956521739...`) for an aspirin query, which
  would make top-5 membership/order implementation-dependent without an
  explicit rule.

## Consequences / 結果
The bundled `sample_molecules.csv` is now a fixed, versioned fixture: any
future addition/removal/reordering of its 20 rows is a breaking change to
REQ-ACHEM-040's acceptance criterion and requires re-verifying all pinned
similarity values and rankings against the new dataset.
