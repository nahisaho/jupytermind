# ADR-0042: Single atomic validation granularity for all 5 structural-biology modules

## Context / 背景
REQ-ASTRUCT-003 needs parameter validation before any module performs a lookup, averaging, scoring, superposition, or contact calculation. Unlike genomics' `sequence-features`, no module in this increment needs per-item batch semantics.

## Decision / 決定
Provide only the atomic whole-run validator API (`register_validator`/`validate_parameters`), omitting the per-item batch-validation API that `ai_genomics_scientist` needs, since no structural-biology module in this increment has batch input.

## Rejected alternatives / 却下した代替案
Pre-emptively adding the unused per-item batch-validation API for forward compatibility: rejected as speculative generality with no current requirement to test it against, which would leave dead, unverifiable code in the shared validator module.

## Consequences / 結果
A future structural-biology requirement with batch-shaped input (e.g. batch contact-map requests) would need to add the per-item API back, mirroring `ai_genomics_scientist`'s pattern, under its own requirement and design.
