# ADR-0045: Kyte-Doolittle scale with a centered in-bounds sliding window

## Context / 背景
REQ-ASTRUCT-020 needs a deterministic per-residue hydrophobicity/burial heuristic, explicitly scoped as a 1D sequence heuristic, not a solvent-accessible-surface or 3D packing calculation.

## Decision / 決定
Look up each residue's exact Kyte-Doolittle value from the fixed scale, compute a centered sliding-window average using only in-bounds residues near sequence edges (no wraparound, no zero-padding), and label each residue `"buried"` iff `window_average > burial_threshold` else `"exposed"`.

## Rejected alternatives / 却下した代替案
Zero-padding or wrapping the window at sequence edges: rejected because either would bias edge-residue averages with fabricated or out-of-context values; restricting the average to genuinely in-bounds residues keeps every reported `window_average` an honest average of real scale values.

## Consequences / 結果
Very short sequences relative to `window_size` will have smaller effective windows near the edges; this is accepted as the correct, honest behavior rather than a defect.
