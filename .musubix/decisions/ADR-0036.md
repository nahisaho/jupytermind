# ADR-0036: Forward-frame-only ORF scan for sequence feature analysis

## Context / 背景
REQ-AGENOM-010 needs a deterministic longest-ORF definition for an arbitrary DNA sequence as part of sequence feature analysis.

## Decision / 決定
Scan only the 3 forward reading frames (0, 1, 2) for the longest ORF starting at `ATG` and closing at the first in-frame stop codon in `{TAA, TAG, TGA}`, breaking ties by lowest frame then lowest start index; report `codon_usage` only for that longest ORF, and `null`/`{}` when none exists.

## Rejected alternatives / 却下した代替案
Also scanning the 3 reverse-complement frames (a full 6-frame ORF scan): rejected as disproportionate scope for this heuristic increment; the requirement's acceptance criteria and bundled test fixtures are defined purely in terms of forward-frame coordinates, and adding reverse-strand scanning would silently change `longest_orf.start_index`/`frame` semantics for any sequence whose true longest ORF is on the reverse strand.

## Consequences / 結果
Any future requirement for reverse-strand ORF detection needs its own new requirement and design revision, not a silent extension of REQ-AGENOM-010.
