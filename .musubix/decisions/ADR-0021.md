# ADR-0021: Rejection-free (BKL) kinetic Monte Carlo with per-realization seed derivation and bounded output horizon

## Context / 背景
REQ-AIMS-040 requires a deterministic, statistically testable kinetic
Monte Carlo tracer-diffusion fixture. Early drafts left the lattice
wrapping, seed derivation, and the relationship between requested output
times and the total simulated time underspecified, which two rounds of
rubber-duck review flagged as blocking ambiguities.

## Decision / 決定
DES-AIMS-040 implements the rejection-free (BKL) algorithm on an
unwrapped (non-periodic coordinate tracking) 2D square lattice with 4
equally rated hop directions, deriving exactly 200 independent realization
seeds as `base_seed + realization_index` for `realization_index` in
`0..199`. A request's output times must satisfy
`0 < t_output <= total_simulated_time`, and sampling never advances a
realization's simulated time past `total_simulated_time`. The reference
fixture uses `base_seed = 7`, `Gamma = 1.0`, `a = 1.0`.

## Rejected alternatives / 却下した代替案
- A single shared seed across all 200 realizations: rejected because it
  would make the realizations statistically dependent, invalidating the
  mean-squared-displacement averaging used by the acceptance test.
- Allowing output times beyond `total_simulated_time` (via extrapolation):
  rejected as physically undefined; the module instead rejects such
  requests under REQ-AIMS-003 before any hop event is drawn.

## Consequences / 結果
Reproducing the acceptance test's MSD/4*Gamma*a^2*t ratio requires using
exactly this base-seed derivation rule; changing the realization count or
seed-derivation formula would invalidate the existing acceptance
tolerance (0.9-1.1).
