# ADR-0120: CHA2DS2-VASc score maps to a 3-tier `risk_category` (`low`/`moderate`/`high`), a documented simplification rather than a verbatim guideline table

## Context / 背景
REQ-AIDS-104 implements the published CHA2DS2-VASc stroke-risk score
(Lip et al., 2010) for atrial fibrillation anticoagulation-discussion
framing. The published literature reports the score's associated
annual stroke-risk percentage per individual point value (0 through 9),
not a single small set of named categories; clinical guidelines vary in
how many risk tiers they collapse that per-point table into, and this
module needs exactly one fixed, documented mapping rather than
reproducing the full per-point percentage table (which would require
bundling additional published risk-percentage data this module's scope
does not otherwise need) or leaving the tiering ambiguous.

## Decision / 決定
Map the integer `score` (range 0-9) to exactly 3 fixed categories:
`score == 0` -> `"low"`, `score == 1` -> `"moderate"`, `score >= 2` ->
`"high"`, matching the commonly cited clinical decision point that
anticoagulation is not routinely recommended at `score == 0`, is
individualized at `score == 1`, and is routinely recommended at `score
>= 2`. REQ-AIDS-104's Constraints explicitly label this 3-tier mapping
"this module's own documented simplification for
anticoagulation-discussion framing, not a verbatim guideline table", so
a reader cannot mistake it for an exact reproduction of any single
cited guideline's full categorical table.

## Rejected alternatives / 却下した代替案
**Return the raw integer `score` only, with no `risk_category` field**:
rejected — REQ-AIDS-104 was explicitly scoped to provide an
anticoagulation-discussion framing aid, not merely a numeric score; a
caller building a notebook-facing summary needs a ready-made category
label rather than re-implementing its own threshold logic.
**Return the full per-point (0-9) published annual-stroke-risk
percentage table as the categorical mapping**: rejected — bundling that
additional published numeric table (which itself varies across
published cohorts) would expand this module's scope and
evidence-sourcing burden well beyond a simple 3-tier categorical label,
for a decision-support aid that already states it is "not a clinical
recommendation".
**Use more than 3 tiers (e.g. a separate tier for `score >= 2` vs.
`score >= 4`)**: rejected — no single widely-cited source agrees on
where additional tier boundaries above `score == 2` should fall, so
adding them would manufacture false precision; 3 tiers is the smallest
set that distinguishes the commonly cited "not recommended / individualize /
recommended" 3-way anticoagulation decision.

## Consequences / 結果
`cha2ds2_vasc_score`'s `risk_category` field is documented as this
module's own simplification, not a guideline citation; any future
change to the tier count or boundaries is a behavior change requiring a
new ADR superseding this one, since it would change every existing
acceptance fixture's expected `risk_category`.
