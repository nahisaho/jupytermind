# ADR-0052: Fixed-order CNS_like / kinase_inhibitor_like / other heuristic classifier

## Context / 背景
REQ-ACHEM-090 needs a deterministic, offline target-class activity label for a single validated SMILES input, explicitly disclosed as not a ChEMBL-trained or experimentally validated classifier.

## Decision / 決定
Evaluate the fixed decision order `CNS_like` (TPSA < 90 and 2.0 <= MolLogP <= 5.0) first, then `kinase_inhibitor_like` (MolWt > 400 and aromatic_ring_count >= 3) second, else `other`, reusing DES-ACHEM-010's `tpsa`/`mol_logp`/`mol_wt` descriptors, and disclose the heuristic's limitation verbatim via the fixed bilingual label.

## Rejected alternatives / 却下した代替案
Training or bundling a real ChEMBL-derived statistical classifier: rejected as disproportionate scope for this offline, no-network-call heuristic increment, and would require a much larger bundled dataset/model than this skill's established lightweight-heuristic convention permits; the fixed-order rule classifier is instead explicitly disclosed as a heuristic, not a trained or validated classifier.

## Consequences / 結果
A future requirement for a genuinely trained bioactivity classifier would need its own requirement, bundled model artifact, and validation methodology, not a silent reinterpretation of this fixed-rule classifier's label.
