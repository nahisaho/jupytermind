# ADR-0023: Kelvin-only SI units and 2D-only plane-strain elasticity for the simplified finite-element module

## Context / 背景
REQ-AIMS-060 requires a deterministic 1D/2D structured-mesh finite-element
solver. Early drafts (a) specified boundary temperatures in Celsius while
REQ-AIMS-005 mandates Kelvin for this module, and (b) allowed
plane-strain linear-elasticity physics on a 1D line mesh, which is
undefined since plane strain is inherently a 2D continuum formulation —
both flagged as blocking by rubber-duck review.

## Decision / 決定
DES-AIMS-060 records all finite-element temperatures in Kelvin only
(reference fixture: 273.15 K / 373.15 K boundary conditions, matching
T(x) = 273.15 + 100*x), consistent with REQ-AIMS-005's shared SI
convention. Plane-strain linear-elasticity physics is restricted to the
2D structured quadrilateral mesh only; the 1D line mesh supports only
steady-state heat conduction. A request for plane-strain elasticity on a
1D mesh is rejected under REQ-AIMS-003 before assembly. Essential
(Dirichlet) boundary conditions are applied by partitioning degrees of
freedom into prescribed and free sets, setting
`u[prescribed_dofs] := prescribed_values`, forming the adjusted load
vector `f_adjusted[free_dofs] := f[free_dofs] -
K[free_dofs, prescribed_dofs] @ prescribed_values`, and forming the
constrained stiffness matrix as the free-free submatrix
`constrained_stiffness := K[free_dofs, free_dofs]` (K is the raw assembled
matrix); before invoking the solver, that constrained stiffness matrix's
reciprocal condition number, computed as
`1 / numpy.linalg.cond(constrained_stiffness, 2)`, must be at or above a
fixed tolerance of `1e-10`, and the free-degree-of-freedom set must be
non-empty; otherwise, the system is rejected as singular/underconstrained.
The raw (unconstrained) assembled stiffness matrix is never tested for
this condition, since it is expected to be singular (rigid-body/null
modes) prior to constraint application. The solve is then
`K[free_dofs, free_dofs] @ u[free_dofs] = f_adjusted[free_dofs]`, and the
reported nodal field sets `u[prescribed_dofs] := prescribed_values`
directly alongside the solved `u[free_dofs]`.

## Rejected alternatives / 却下した代替案
- Supporting a separate 1D axial-bar elasticity formulation: rejected as
  out of scope for this change; it would need its own constitutive law,
  degree-of-freedom definition, and acceptance fixture, none of which are
  required by the current requirement set.
- Allowing Celsius as a display-only conversion layer: rejected in favor
  of keeping the stored/recorded arrays exclusively in Kelvin, avoiding
  any ambiguity about which unit a consumer of `arrays` is reading.

## Consequences / 結果
A future 1D elasticity module would require a new requirement, design
component, and ADR; this module's 1D path is heat-conduction-only by
design.
