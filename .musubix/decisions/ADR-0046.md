# ADR-0046: Fixed-formula geometric/compositional docking-score heuristic

## Context / 背景
REQ-ASTRUCT-030 needs a deterministic protein-protein "docking score" with no 3D structure, no energy function, and no external docking engine, mirroring the chemistry skill's analogous ADR-0032 ligand-docking-score heuristic.

## Decision / 決定
Compute `score = 0.5*size_term + 0.25*hydrophobic_complementarity + 0.25*charge_complementarity` from the fixed formulas over `interface_area_A2` and the two partners' `hydrophobic_count`/`charged_count`, using the documented `800.0` Å² typical-interface-size constant, and disclose the heuristic's limitation verbatim via the fixed bilingual label.

## Rejected alternatives / 却下した代替案
Computing a physically grounded interface score from 3D coordinates (e.g. buried-surface-area or electrostatic-potential calculations): rejected as disproportionate scope for this increment and inconsistent with the no-network-call, no-external-solver convention; it would also imply a level of physical accuracy this heuristic does not have.

## Consequences / 結果
This score has no claim to binding-affinity accuracy; a future requirement for a physically grounded docking score would need a new requirement, likely with a heavier dependency, not a revision of this fixed formula.
