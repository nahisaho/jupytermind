# ADR-0060: Warning-only body-text/cited-value cross-check in notebook_audit

## Context / 背景
`DES-AIDS-054` (REQ-AIDS-066) addresses GitHub #45: `audit_notebook`
confirmed a cited value resolved against a real executed cell, but never
checked whether an insight's own prose actually stated (or contradicted)
that value, so a notebook could cite a correct number while describing a
different one in its body text with no audit finding.

## Decision / 決定
Add `_body_mentions_value`, a plain-substring-plus-rounded-numeric-match
check over the insight's body text (evidence fences stripped), and surface
a mismatch as a **warning**-severity `NotebookAuditFinding`, not an error
that fails `report.ok`. Warning severity is the decision point: the check
deliberately tolerates reasonable paraphrase/rounding (matching at the
stated decimal precision) so it flags genuine contradictions without
making every notebook with slightly-imprecise prose fail audit.

## Rejected alternatives / 却下した代替案
- **Error-severity finding (failing `report.ok`)**: rejected because
  plausible paraphrasing (e.g. body says "about 0.95" for a cited "0.954")
  would then break previously-passing notebooks with no actual
  contradiction, trading false positives for a false sense of rigor.
- **Exact string match only (no rounding tolerance)**: rejected because it
  would flag essentially every notebook that states a rounded or
  differently-formatted version of its own cited number, making the check
  too noisy to be useful.
- **Requiring a second full notebook re-parse/re-execution to verify body
  claims against live cell state**: rejected as unnecessary — the markdown
  source is already in memory at this point in `audit_notebook`, so no new
  I/O or execution is needed to perform this text-level check.

## Consequences / 結果
Any future body-text audit heuristic in `notebook_audit` should default to
warning severity unless a false-negative on a genuine contradiction is
demonstrably worse than the false-positive rate of stricter matching.
Covered by the REQ-AIDS-066 acceptance tests in
`tests/test_notebook_audit.py`.
