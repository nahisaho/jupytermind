# ADR-0047: Kabsch SVD-based superposition with documented rank-deficiency behavior

## Context / 背景
REQ-ASTRUCT-040 needs a deterministic structural-similarity RMSD after optimal superposition of two equal-length coordinate sets, including defined behavior for the degenerate case where the point sets are collinear or coincident.

## Decision / 決定
Use the standard Kabsch algorithm (centroid-centering, cross-covariance matrix, `numpy.linalg.svd`, determinant-sign reflection correction) to compute `rotation_matrix`/`translation`, and explicitly document that when the cross-covariance matrix is rank-deficient (fewer than 2 nonzero singular values), `rmsd` remains deterministic but `rotation_matrix`/`translation` are not guaranteed unique, with no additional canonicalization step applied.

## Rejected alternatives / 却下した代替案
Adding ad hoc canonicalization for the rank-deficient case (e.g. an arbitrary fixed rotation when singular values are degenerate): rejected because the degenerate case has no single physically meaningful rotation to prefer, and fabricating one would misrepresent the result as more determined than the geometry actually supports; documenting the limitation is more honest than silently picking an arbitrary convention.

## Consequences / 結果
Callers must treat `rotation_matrix`/`translation` as informative only (not unique) whenever the input point sets are collinear or coincident.
