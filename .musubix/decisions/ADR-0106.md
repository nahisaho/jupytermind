# ADR-0106: Local RDKit-only structure format conversion (SMILES/InChI/InChIKey/Molblock), no network lookups

## Context / 背景
REQ-ACHEM-110 adds a chemical-structure format-conversion module. The `aipoch/openscience-skill-marketplace` catalog (used only as a domain-gap-analysis source, per this skill's existing ToolUniverse-inspired precedent) includes several tools that convert or enrich structures via external database lookups (e.g. PubChem/ChEMBL/DrugBank identifier resolution). This skill's established architecture (ADR-0025 et al.) commits to no network calls and no external solver binaries.

## Decision / 決定
Scope this module to exactly 3 input formats (`smiles`, `inchi`, `molblock`) and 4 output formats (`smiles`, `inchi`, `inchikey`, `molblock`), implemented solely with RDKit's own local parse/render functions (`Chem.MolFromSmiles`/`Chem.MolToSmiles`, `Chem.inchi.MolFromInchi`/`Chem.inchi.MolToInchi`/`Chem.inchi.MolToInchiKey`, `Chem.MolFromMolBlock`/`Chem.MolToMolBlock`). `inchikey` is accepted only as an output format, since InChIKey is a one-way hash with no reverse parser. No PubChem/ChEMBL/DrugBank identifier resolution of any kind is in scope.

## Rejected alternatives / 却下した代替案
Adding PubChem CID / ChEMBL ID / DrugBank ID as additional input or output "formats": rejected because resolving those identifiers requires a network call to an external database, which conflicts with this skill's no-network-call architectural constraint (ADR-0025) and would also require handling third-party service availability/rate-limiting, an entirely different failure-mode class than local parsing.
Allowing `inchikey` as an input format via an internal reverse-lookup table: rejected — InChIKey is cryptographically one-way by design; no local, no-network reverse mapping is chemically valid in general, so permitting it as an input would be misleading.

## Consequences / 結果
Any future additional structure format (e.g. SDF, PDB, SMARTS-as-structure) should follow this same pattern: add it only if RDKit itself provides a local, no-network parser/writer; database-identifier formats remain permanently out of scope for this skill under the existing no-network-call constraint, consistent with REQ-ACHEM-040's bundled-dataset-only similarity search and REQ-ACHEM-050's heuristic (non-database) docking score.
