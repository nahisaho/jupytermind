# ADR-0054: Seed-variability summary statistic (range) for repeated-seed comparisons

## Context / 背景
`DES-AIDS-090` (REQ-AIDS-090) must summarize how much a control-versus-
treatment comparison's outcome varies purely due to random seed choice,
across a caller-supplied sequence of split/model seeds, so that a later
adoption decision (`DES-AIDS-091`) can distinguish "noise" from "real
improvement."

## Decision / 決定
Use the observed improvement range, `max(improvements) - min(improvements)`,
as `SeedComparisonSummary.seed_variability`. This is a simple, deterministic,
and easy-to-explain-in-a-notebook-commentary statistic: it directly answers
"how far apart were the best and worst outcomes I saw across seeds?" and
needs no distributional assumptions.

## Rejected alternatives / 却下した代替案
- Sample standard deviation of improvements: rejected because with the small
  seed counts typical of notebook experimentation (often 3-10 seeds), a
  standard deviation understates the practical worst-case spread a user
  should guard against, and requires explaining a statistical concept the
  bilingual notebook commentary (REQ-AIDS-010 evidence rules) would need to
  translate accurately in both languages.
- Interquartile range: rejected as unnecessarily complex for small seed
  counts (quartiles are poorly defined for n < 4) and not meaningfully more
  robust than the simple range at this scale.
- A fixed, caller-independent constant threshold: rejected because seed
  variability is inherently dataset- and model-specific; a fixed constant
  would either be too strict (flagging real improvements as noise) or too
  loose (adopting changes that are themselves within observed seed noise),
  which is precisely the problem REQ-AIDS-090/091 exist to solve.

## Consequences / 結果
`DES-AIDS-091`'s default adoption threshold is defined directly in terms of
this range statistic (`threshold == summary.seed_variability` unless
explicitly overridden), so changing the variability statistic here would
also require revisiting `DES-AIDS-091`'s default threshold semantics.
