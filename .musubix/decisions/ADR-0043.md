# ADR-0043: Plain JSON-safe RunRecord with numpy-only provenance

## Context / 背景
REQ-ASTRUCT-004 needs reproducible, JSON-safe run evidence for every structural-biology module invocation. Every result in this skill (scalars, strings, booleans, lists, and nested dicts/lists of these) is already JSON-safe, and no module uses scipy, so only `numpy_version` provenance is needed, unlike genomics' `numpy_version` plus `scipy_version` pair.

## Decision / 決定
Record `{metadata: {module, schema_version, numpy_version}, parameters, result}` for every successful run, with no ndarray codec and no scipy provenance field, since no module's computation needs scipy.

## Rejected alternatives / 却下した代替案
Reusing the genomics skill's `RunRecord` schema verbatim, including an unused `scipy_version` field: rejected because it would record a provenance field no module in this skill's computation depends on, misrepresenting what is actually reproducible evidence for this skill.

## Consequences / 結果
If a future structural-biology module introduces a scipy dependency, this schema would need a design revision to add `scipy_version`, mirroring the genomics skill's `RunRecord`.
