# ADR-0019: 2D periodic square box with minimum-image convention for the molecular dynamics fixture

## Context / 背景
REQ-AIMS-020 requires a deterministic, reproducible molecular dynamics
reference fixture. An earlier draft mixed a "periodic cubic box" (3D)
statement with a 2D four-particle acceptance fixture, which rubber-duck
review flagged as a dimensional inconsistency that would let
implementations diverge on box/cutoff handling.

## Decision / 決定
DES-AIMS-020 commits to a 2D periodic square box for this module (not a
3D cubic box), using the minimum-image convention for periodic pairwise
distances and rejecting any cutoff radius greater than half the box side
length. The stability time-step bound is the explicit heuristic
dt_bound = 0.005 * sigma * sqrt(mass/epsilon), a fixed fraction of the
Lennard-Jones reduced oscillation period, applied uniformly rather than
derived per-request from a full linear-stability analysis (which is not
well-defined for the nonlinear Lennard-Jones potential).

## Rejected alternatives / 却下した代替案
- A 3D cubic box: rejected because it would require 3D fixture
  coordinates and a different (already-reviewed) acceptance fixture;
  staying 2D keeps the module's scope aligned with the other
  mesoscale/lattice modules and the already-validated 4-particle fixture.
- A rigorous nonlinear stability bound: rejected as infeasible to derive
  in closed form for a general Lennard-Jones configuration; the fixed
  heuristic fraction is explicit, reproducible, and sufficient for the
  module's energy-drift acceptance test.

## Consequences / 結果
This module cannot be directly reused for 3D bulk MD without a new
requirement and design revision; it is explicitly scoped to 2D periodic
systems only.
