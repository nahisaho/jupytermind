# ADR-0018: Fixed double-well potential and explicit linear-stability bounds for phase-field integration

## Context / 背景
REQ-AIMS-010 requires a deterministically testable phase-field module.
An initial draft left the bulk free-energy potential and the forward-Euler
stability bound implicit, which two rounds of rubber-duck review found
would let conforming implementations diverge in actual numerical
trajectories and admit unstable time steps (notably an initially
non-conservative Cahn-Hilliard bound).

## Decision / 決定
DES-AIMS-010 fixes the bulk potential to exactly f(c) = c^2*(1-c)^2 (no
configurable potential family), uses the periodic five-point Laplacian
L(c)[i,j] = (c[i+1,j]+c[i-1,j]+c[i,j+1]+c[i,j-1]-4c[i,j])/dx^2, and derives
the chemical potential mu = f'(c) - kappa*L(c). It reports the explicit
linear-stability dt_bound = 2/(M*(2+kappa*lambda_max)) for Allen-Cahn and
dt_bound = 2/(M*lambda_max*(2+kappa*lambda_max)) for Cahn-Hilliard, where
lambda_max = 8/dx^2, matching REQ-AIMS-010's acceptance fixture values
(0.2 and 0.025 respectively for M=kappa=dx=1).

## Rejected alternatives / 却下した代替案
- A pluggable/arbitrary bulk potential function: rejected because it would
  make the acceptance criteria's analytic stability bounds and reference
  energy values implementation-dependent, defeating deterministic TDD
  testability.
- The originally drafted Cahn-Hilliard bound dx^4/(8*M*kappa): rejected
  after rubber-duck review proved it unstable (4x too large) relative to
  the correct linearized eigenvalue-based bound.

## Consequences / 結果
Future phase-field potential variants (e.g., a tilted or asymmetric
double-well) would require a new requirement and a new module variant;
this module only ever implements the fixed symmetric potential.
