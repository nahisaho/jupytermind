# ADR-0108: Embedded fixed BLOSUM62 + linear weighted-sum heuristic for variant pathogenicity, not a trained classifier or external predictor

## Context / 背景
REQ-AGENOM-070 adds a missense-variant pathogenicity-prediction
heuristic module. Real pathogenicity predictors (PolyPhen-2, SIFT,
CADD, REVEL, AlphaMissense) are either trained statistical/ML models
over large curated variant databases, or require network calls to an
external scoring service or a large bundled model file — both of which
conflict with this skill's no-network-call, no-external-binary
architecture (ADR-0025's precedent) and with the repository's existing
pattern of small, auditable, fully-offline heuristic modules (e.g.
DES-AGENOM-030's fixed-PFM splice-site scorer, which carries an
explicit bilingual heuristic-limitation label).

## Decision / 決定
Implement exactly the fixed, fully-documented formula that
REQ-AGENOM-070's Statement defines: look up `blosum_score` from a
single embedded, hardcoded BLOSUM62 substitution matrix (the standard
published 20x20 amino-acid substitution matrix, bundled as a Python
literal — no external file, no network fetch), derive
`dissimilarity = clip((3 - blosum_score) / 7, 0, 1)` (a fixed linear
rescaling of the BLOSUM62 score range into `[0, 1]`), compute
`pathogenicity_score = clip(0.5 * dissimilarity + 0.35 *
conservation_score + (0.15 if in_functional_domain else 0.0), 0, 1)`
as a fixed linear weighted sum of 3 independent signals, and classify
the result into 5 fixed tiers (`benign`, `likely_benign`,
`uncertain_significance`, `likely_pathogenic`, `pathogenic`) by fixed
thresholds (`0.3`, `0.5`, `0.7`, `0.85`, each a lower-inclusive
boundary).

## Rejected alternatives / 却下した代替案
Training or bundling a real statistical/ML pathogenicity classifier
(e.g. a logistic-regression or gradient-boosted model fit on
ClinVar/HGMD-style labeled variants): rejected — this skill's
established pattern (consistent with every other `ai-genomics-scientist`
module) is a fixed, auditable, zero-training-data heuristic; bundling
real labeled clinical variant data would also raise data-licensing and
scope concerns far beyond this module's heuristic intent.
Calling an external pathogenicity-prediction API (e.g. a PolyPhen-2 or
CADD web service): rejected outright — violates the no-network-call
architectural constraint and would make every run non-reproducible
against a third-party service's uptime/versioning.
Using only `blosum_score` (dropping `conservation_score` and
`in_functional_domain` as independent weighted signals): rejected —
REQ-AGENOM-070 was explicitly designed to combine 3 independent,
named, user-supplied signals; collapsing to a single BLOSUM-only score
would both reduce acceptance-fixture coverage and misrepresent the
module as doing less than it is documented to do.
Using exclusive (non-lower-inclusive) tier boundaries: rejected — an
exclusive-lower/inclusive-upper convention would make the 5 tiers
impossible to express as a simple ascending `if score < threshold`
chain without an off-by-one at each boundary; the chosen
lower-inclusive convention is stated exactly once as the general rule
and verified by the boundary/just-below fixture pairs added to
REQ-AGENOM-070's Acceptance criteria.

## Consequences / 結果
This module's score is a heuristic illustrative scoring scheme, not a
validated clinical pathogenicity predictor (not PolyPhen-2, not SIFT,
not CADD, not AlphaMissense). REQ-AGENOM-070 itself already requires
that the module not be presented as a validated clinical
pathogenicity call; documenting this limitation in `SKILL.md`
(mirroring DES-AGENOM-030's existing heuristic-label pattern) is this
ADR's selected implementation approach for satisfying that existing
constraint, not a new mandatory deliverable beyond what REQ-AGENOM-070
already requires. The embedded BLOSUM62 matrix and the 3 fixed weights
(`0.5`, `0.35`, `0.15`) are frozen constants for this module; changing
them would change every existing acceptance fixture's expected
`pathogenicity_score`/`classification` and must be tracked as a new ADR
superseding this one.
