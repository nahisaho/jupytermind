# ADR-0072: Bound sub-threshold p-value display via a shared `"p < 1e-4"` helper instead of raw formatting

## Context / 背景
`DES-AIDS-053` (REQ-AIDS-065, GitHub #37) addresses `correlation`'s
interpretation text displaying the existing `f"p={p_value:.4g}"`
scientific-notation formatting even for extremely small p-values (e.g.
`p=1.234e-11`), which conveys a misleadingly specific numeric value at a
scale where the exact magnitude is not practically meaningful, and is
harder to read at a glance than a bounded "less-than" statement.

## Decision / 決定
Introduce a shared `p_display(p_value)` helper: when `p_value < 1e-4`, it
returns the literal string `"p < 1e-4"`; otherwise it returns the
existing `f"p={p_value:.4g}"` formatting unchanged. Both of
`_interpret`'s significant and non-significant sentence branches
(ADR-0070) call this one helper, so the displayed p-value is always
identical regardless of which branch is ultimately selected, and formatting
for any `p_value >= 1e-4` is completely unaffected.

## Rejected alternatives / 却下した代替案
- **Lowering `:.4g`'s precision uniformly for all p-values instead of a
  dedicated bounded-display branch**: rejected — this would still show a
  misleadingly specific (if shorter) number for very small p-values
  (e.g. `p=1.23e-11`), rather than communicating that the exact value is
  not practically meaningful below the bound; a literal "less-than"
  statement is the clearer, more honest representation at that scale.
- **Applying the `"p < 1e-4"` bound inline in `_interpret` separately for
  each of the two branches, instead of a single shared helper**:
  rejected — duplicating the formatting logic risks the two branches
  drifting out of sync (e.g. a future edit to one threshold/format
  string without updating the other), which a single shared
  `p_display` call site structurally prevents.
- **Choosing a different bound (e.g. `1e-3` or `1e-5`) instead of
  `1e-4`**: rejected as arbitrary relative to `1e-4` — `1e-4` is
  specifically documented in REQ-AIDS-065's acceptance criteria as the
  agreed bound, consistent with conventional statistical reporting
  practice of not over-stating precision beyond what is practically
  interpretable.

## Consequences / 結果
Any future change to p-value formatting (e.g. a different bound or
display format) must update `p_display` alone; both interpretation
branches will automatically stay consistent. Covered by the REQ-AIDS-065
acceptance tests in `tests/test_stats_analysis.py`.
