# ADR-0013: Unconditional `tight_layout`/`bbox_inches="tight"` chart save (no length-heuristic gating)

## Context / 背景
REQ-AIDS-058 requires chart title/axis/tick labels to never be clipped in
the saved PNG, replacing an implementation that could clip long labels.

## Decision / 決定
DES-AIDS-046 calls matplotlib's `Figure.tight_layout()` (falling back to
`constrained_layout` if `tight_layout` raises, e.g. for 3D axes) and passes
`bbox_inches="tight"` to `savefig` on every `render_chart` call,
unconditionally — not gated behind a heuristic "label looks long" check —
so clipping avoidance is deterministic and does not depend on a brittle
length threshold.

## Rejected alternatives / 却下した代替案
- A heuristic trigger (e.g. only apply tight layout when a label exceeds N
  characters): rejected because any fixed threshold is brittle across
  fonts/DPI/figure sizes and would leave some genuinely clipped cases
  unfixed while still being nondeterministic from the caller's point of
  view.
- Enlarging the fixed canvas size instead of tightening the bounding box:
  rejected because a fixed enlargement does not generalize to arbitrarily
  long labels and would waste canvas space for short labels.

## Consequences / 結果
`bbox_inches="tight"` changes the saved PNG's pixel dimensions to fit the
tightened bounding box; no requirement or existing test depends on a fixed
output size, so this is an accepted, intentional side effect. The layout
step must run after font configuration (ADR-0010) and after title/axis
text is set, since `tight_layout` measures already-rendered text metrics.
