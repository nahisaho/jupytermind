# ADR-0040: Full-matrix Needleman-Wunsch with a fixed traceback tie-break order

## Context / 背景
REQ-AGENOM-050 needs a deterministic global pairwise DNA alignment with a fixed scoring scheme and reproducible output for equal-scoring traceback paths.

## Decision / 決定
Build the full Needleman-Wunsch dynamic-programming matrix with `match=+1, mismatch=-1, gap=-2`, and resolve traceback ties by the fixed order diagonal, then up, then left, applied globally throughout the traceback.

## Rejected alternatives / 却下した代替案
Using a banded or heuristic alignment approximation (e.g. a fixed-width band) for performance: rejected because the requirement specifies an exact global alignment, and any approximation could silently change `score`/`identity` for sequences whose true optimal alignment falls outside an arbitrary band, with no acceptance criteria defining an acceptable approximation error.

## Consequences / 結果
This module's complexity is O(len(seq1) * len(seq2)); very long sequences would need a new requirement and design before this module could be asked to scale beyond the sizes implied by its current test fixtures.
