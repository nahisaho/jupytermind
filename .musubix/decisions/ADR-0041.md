# ADR-0041: Reuse the chemistry-skill static-manifest dispatcher for structural biology

## Context / 背景
REQ-ASTRUCT-001/002 need the same bilingual, single-dispatch request router shape already accepted for `ai-chemistry-scientist` and `ai-genomics-scientist`: a checked-in JSON manifest, NFKC-normalized substring matching, single-match dispatch, clarification on ambiguity, and rejection on no match.

## Decision / 決定
Reuse the established dispatcher pattern unmodified except for the structural-biology-specific manifest file path and the 5 method keys (`secondary-structure-heuristic`, `hydrophobicity-burial-heuristic`, `protein-protein-docking-score`, `structural-similarity-rmsd`, `residue-contact-map`), reusing `ai_data_scientist.language_router.detect_language` for language detection exactly as the sibling skills do.

## Rejected alternatives / 却下した代替案
Designing a structural-biology-specific dispatcher (for example one that special-cases coordinate-bearing requests): rejected because no requirement drives a different dispatch policy, and duplicating the already-reviewed pattern would add unreviewed, untested surface area for no behavioral benefit.

## Consequences / 結果
Any future change to the shared dispatch contract should be made once in the shared pattern description and propagated to every skill reusing it.
