# ADR-0034: Shared validator registry carried over from the chemistry skill

## Context / 背景
REQ-AGENOM-003 needs both atomic whole-run validation (for 4 of the 5 modules) and per-item batch validation (for `sequence-features` alone). The chemistry skill already defines and tests this exact two-granularity registry pattern (`register_validator`/`validate_parameters` plus `register_batch_item_validator`/`validate_batch_item`).

## Decision / 決定
Carry over the chemistry skill's validator registry API unchanged, keyed by manifest method name, with genomics-specific validator functions registered at import time for each of the 5 modules.

## Rejected alternatives / 却下した代替案
Inventing a new validation API shaped specifically around DNA/variant domains: rejected because the atomic-vs-per-item split the chemistry skill already solved generalizes directly to genomics' one per-item module (`sequence-features`) and four atomic modules, with no genomics-specific validation concept the existing API cannot express.

## Consequences / 結果
Any future genomics module needing a third validation granularity (e.g. streaming validation) would need a new ADR, since this registry currently supports only the two granularities above.
