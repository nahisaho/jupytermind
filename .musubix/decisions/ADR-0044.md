# ADR-0044: Fixed Chou-Fasman-style propensity table with a helix>sheet>coil tie-break

## Context / 背景
REQ-ASTRUCT-010 needs a deterministic per-residue secondary-structure classification, explicitly disclosed as illustrative, not a validated predictor.

## Decision / 決定
Use the exact fixed per-residue propensity table given in the requirement, assign each residue the class with the largest propensity, and break any exact tie by the fixed preference order helix (H) over sheet (E) over coil (C), with no sliding-window smoothing.

## Rejected alternatives / 却下した代替案
Adding windowed smoothing over neighboring residues (real Chou-Fasman-style propensity averaging): rejected as out of scope for this requirement, which specifies a direct per-residue lookup with no windowing; the bilingual limitation label explicitly discloses the absence of real Chou-Fasman statistics or windowing instead of silently approximating them.

## Consequences / 結果
A future requirement for a windowed or ML-based secondary-structure predictor would need its own requirement and design, not a silent change to this fixed lookup table.
