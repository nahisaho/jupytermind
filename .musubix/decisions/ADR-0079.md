# ADR-0079: Persist manuscript language from the triggering instruction, not from later artifact inspection

## Context / 背景
`DES-AISCI-007` (`REQ-AISCI-010`, `CHANGE-001`) needs peer review and other
downstream phases to know whether a manuscript should be treated as Japanese
or English. The design question is when and from what source that language
classification should be derived so routing stays deterministic even if the
manuscript text mixes languages or is transformed later.

## Decision / 決定
Ai-scientist records manuscript language immediately in the
manuscript-writing flow by calling the shared `detect_language(instruction)`
function on the same instruction that triggered manuscript generation, then
storing the result inside the manuscript evidence metadata as
`{"language": "ja" | "en", "sourceMarkdownPath": ...}`. The same
detector implementation is reused from `ai_scientist.language`, which in
turn delegates to `ai_data_scientist.language_router.detect_language`, so
ai-scientist maintains only one tuned language classifier.

This turns manuscript language into durable workflow metadata instead of a
late heuristic over generated text. Downstream routing therefore depends on
an explicit project record, not on re-reading or reinterpreting the
manuscript file after additional rendering or editing steps.

## Rejected alternatives / 却下した代替案
- **Detecting language from the generated manuscript contents after `tech-writer` returns**: rejected — the artifact may include citations, code, or mixed-language sections, and `DES-AISCI-007` explicitly ties language to the user's triggering instruction rather than to a later textual guess.
- **Re-detecting manuscript language each time peer review runs**: rejected — repeated detection would make routing sensitive to later edits and would remove the durable metadata record that the design requires other phases to consult.
- **Adding a second ai-scientist-specific classifier tuned separately from the entry orchestrator's detector**: rejected — the component constraint is to reuse the same detection function as `DES-AISCI-001`, so a second classifier would create split behavior between response language and manuscript metadata.

## Consequences / 結果
Future downstream consumers must treat manuscript language as persisted
workflow metadata and update the shared detector in one place if language
rules change. Covered by the acceptance tests in
`tests/test_ai_scientist_delegation.py`.
