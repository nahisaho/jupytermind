# ADR-0024: Bracketed root-finding on the symmetric regular-solution coexistence equation instead of common-tangent construction

## Context / 背景
REQ-AIMS-070 requires a deterministic binary-phase binodal calculation
without a full CALPHAD/TDB solver. An early draft claimed a "closed-form"
solution and left the coexistence equation's trivial root (x=0.5) and
singular endpoints (x=0, x=1) unexcluded, both flagged by rubber-duck
review as blocking: the equation is transcendental (no closed form), and
an unconstrained root-finder could converge to the physically
uninteresting symmetric trivial root instead of the two binodal
compositions.

## Decision / 決定
DES-AIMS-070 computes the symmetric regular-solution coexistence equation
`ln(x/(1-x)) + (Omega/(R*T))*(1-2*x) = 0` directly (not via common-tangent
construction on a sampled free-energy curve) and solves it with an
independent bracketed root-finder restricted to the open intervals
`(0, 0.5)` for `x_alpha` and `(0.5, 1)` for `x_beta`, explicitly excluding
the trivial `x = 0.5` root and the singular `x = 0`/`x = 1` endpoints. A
request with `Omega <= 0`, `T <= 0`, or `T >= T_c` (`T_c = Omega/(2R)`) is
rejected under REQ-AIMS-003 before any root-finding attempt.

## Rejected alternatives / 却下した代替案
- Common-tangent construction on a discretized free-energy curve:
  rejected as an unnecessary numerical layer for the symmetric
  regular-solution model, where the coexistence condition reduces to a
  single closed transcendental equation solvable directly by bracketed
  root-finding.
- An unbracketed general-purpose root-finder (e.g., Newton's method from
  an arbitrary starting point): rejected because it could converge to the
  trivial `x = 0.5` root depending on the starting guess, which is not a
  physically meaningful binodal composition.

## Consequences / 結果
This module is limited to the single symmetric regular-solution binary
case; multicomponent or asymmetric (Redlich-Kister) models would need a
new requirement, design component, and root-finding strategy.
