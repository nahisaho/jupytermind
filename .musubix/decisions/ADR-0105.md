# ADR-0105: Deterministic fixed-sort-key fragment selection instead of RDKit's `LargestFragmentChooser` default

## Context / 背景
REQ-ACHEM-100 adds a SMILES salt-removal/structure-standardization module. RDKit ships `rdMolStandardize.LargestFragmentChooser`, which claims to pick the "largest" disconnected fragment, but empirical testing in this session (RDKit 2026.03.6) showed its default scoring does not consistently select the fragment with the greatest heavy-atom count (e.g. for `"CC(=O)O.CCN"` it selected the 3-heavy-atom `CCN` fragment over the 4-heavy-atom `CC(=O)O` fragment), making its tie-break/scoring behavior unsuitable as a documented, testable requirement.

## Decision / 決定
Implement fragment selection as an explicit, fully-specified, deterministic sort: split the input with `Chem.GetMolFrags(mol, asMols=True, sanitizeFrags=False)`, score each fragment by the sort key `(-heavy_atom_count, canonical_smiles)`, and select the first-ranked fragment as `standardized_smiles`; report every other fragment, in the same ascending sort-key order, as `removed_fragments`. This uses only `GetNumHeavyAtoms()` and `Chem.MolToSmiles()` — both well-documented, stable RDKit APIs — not the `MolStandardize` heuristic chooser.

## Rejected alternatives / 却下した代替案
Using `rdMolStandardize.LargestFragmentChooser()` directly: rejected because its internal fragment-scoring and tie-break rule is not documented precisely enough to write a falsifiable acceptance criterion, and empirical testing showed it does not simply pick the fragment with the most heavy atoms.
Using molecular weight instead of heavy-atom count as the primary sort key: rejected to keep the rule's reference quantity (heavy-atom count) identical to the one already used throughout this skill (e.g. DES-ACHEM-060's Ghose filter), avoiding introducing a new descriptor dependency for this module alone.

## Consequences / 結果
This module's "salt removal" is a documented heuristic (larger-fragment-wins), not a curated salt/solvent lookup table; it can misclassify a genuine covalent multi-component structure (e.g. a cocrystal) as having a removable "salt" fragment. This limitation is disclosed in REQ-ACHEM-100's Constraints and must appear in SKILL.md.
