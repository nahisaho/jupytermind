# ADR-0025: Static manifest dispatcher reused from ai-materials-scientist for cheminformatics modules

## Context / 背景
REQ-ACHEM-001/002 require `ai-chemistry-scientist` to route a bilingual
natural-language request to exactly one of its cheminformatics modules —
originally 5 (molecular descriptors, ADMET prediction, QSAR modeling,
molecular similarity, docking score) and now, after the second increment
adding REQ-ACHEM-060/070/080/090 (drug-likeness filters, structural
alerts, molecular formula/exact mass, bioactivity classification), 9 —
asking a clarification question on an ambiguous match and rejecting on
no match. DES-ACHEM-001 needs a concrete dispatch mechanism.

## Decision / 決定
Reuse the manifest-dispatch pattern already proven twice in this
repository (`ai-scientist`'s `src/ai_scientist/manifest.py` and
`ai-materials-scientist`'s `src/ai_materials_scientist/dispatch.py`): a
single static JSON file (`.github/skills/ai-chemistry-scientist/manifest.json`)
maps each method name and its bilingual synonyms to
exactly one module handler function. `dispatch()` classifies the request
text against this static manifest and invokes at most one handler, reusing
`ai_data_scientist.language_router.detect_language` for language
detection — the same shared helper `ai_materials_scientist.dispatch`
already depends on, avoiding a third independent language-detection
implementation.

## Rejected alternatives / 却下した代替案
- A new, independent language-detection implementation specific to this
  skill: rejected because `ai_data_scientist.language_router
  .detect_language` is already a shared, tested utility used by
  `ai_materials_scientist`; duplicating it would create divergence risk
  with no requirement calling for chemistry-specific language detection.
- Dynamic plugin discovery: rejected for the same reasons as ADR-0015 —
  no requirement calls for runtime-extensible modules, and the module set
  is fixed by its governing requirements (REQ-ACHEM-010 through 050 for
  the first increment, REQ-ACHEM-060/070/080/090 for the second).

## Consequences / 結果
Adding another cheminformatics module later requires updating the static
manifest and its synonym list, not just dropping in a new file; this is an
accepted cost in exchange for deterministic, fully auditable dispatch
behavior, consistent with the sibling `ai-materials-scientist` skill. This
cost was already paid once, when the second increment (REQ-ACHEM-060
through 090) extended the dispatcher from 5 to 9 routed methods without
changing this decision's mechanism.
