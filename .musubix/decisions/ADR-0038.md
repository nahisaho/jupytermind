# ADR-0038: Fixed illustrative 9-position PWM for splice-site scoring

## Context / 背景
REQ-AGENOM-030 needs a deterministic splice-site "strength" heuristic over a fixed 9-base donor-site window, explicitly disclosed as not a validated predictor such as SpliceAI.

## Decision / 決定
Use the exact fixed position-frequency matrix given in the requirement, compute `score_bits` as the sum of `log2(freq / 0.25)` log-odds terms over all 9 positions, and require the canonical `GT` dinucleotide at positions 0,+1 before any score is computed, rejecting the request otherwise with the exact named constraint.

## Rejected alternatives / 却下した代替案
Deriving the PWM from a real reference splice-site frequency dataset: rejected as out of scope for this offline, no-network-call heuristic increment, and would misrepresent the module's illustrative nature; the bilingual limitation label is instead the chosen mitigation, fixed verbatim in both the design and SKILL.md.

## Consequences / 結果
Any future requirement for a genuinely data-derived splice-site model would need a new requirement bundling that reference dataset, not a revision of this fixed illustrative PWM.
