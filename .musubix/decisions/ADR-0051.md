# ADR-0051: Direct RDKit molecular formula / exact mass wrapper

## Context / 背景
REQ-ACHEM-080 needs deterministic molecular formula and exact mass reporting for a single validated SMILES input, with no new architectural surface beyond the skill's existing descriptor/validation/evidence pattern.

## Decision / 決定
Call `rdMolDescriptors.CalcMolFormula(mol)` and `Descriptors.ExactMolWt(mol)` directly on the already-validated parsed molecule, introducing no new metadata fields beyond the existing `rdkit_version` provenance REQ-ACHEM-004 already requires.

## Rejected alternatives / 却下した代替案
Computing an average (not exact/monoisotopic) molecular weight instead, or adding a second average-mass field: rejected because the requirement's acceptance criterion specifically names exact mass, and adding an unrequested second mass field would expand the result shape beyond what REQ-ACHEM-080 actually specifies.

## Consequences / 結果
A future requirement for average molecular weight would need its own acceptance criterion and result field, added explicitly rather than folded into this module.
