# ADR-0093: Paired-resampling bootstrap engine for interval-only metric comparison (DES-AIDS-068)

## Context / 背景
`DES-AIDS-068` (REQ-AIDS-081) requires comparing aligned control/treatment
predictions (via a caller-supplied `metric_fn` and `y_true`) or aligned
fold-level scores (with neither), by resampling matched pairs and reporting
a confidence interval without claiming a hypothesis-test p-value. A naive
unpaired bootstrap (independently resampling control and treatment) would
break the row/fold alignment that the comparison depends on, and silently
computing a p-value from the bootstrap distribution would misrepresent an
interval-estimation procedure as a hypothesis test.

## Decision / 決定
`_run_paired_bootstrap` draws one shared set of resampled indices per
iteration (`_sample_paired_indices`) and applies that same index set to both
`control` and `treatment` (and `y_true`, when supplied), so every bootstrap
sample preserves the original pairing. When `y_true` has repeated class
labels, `_sample_paired_indices` draws indices within each label stratum so
that class-dependent metrics (e.g. ROC AUC) remain well-defined on every
resampled iteration. The reported `ExperimentResult.confidence_interval` is
the empirical `(alpha/2, 1 - alpha/2)` quantile pair of the bootstrap
difference distribution, and `p_value` is set to `NaN` (see ADR for
DES-AIDS-069) to signal that this path performs interval estimation only.

## Rejected alternatives / 却下した代替案
- Independent (unpaired) resampling of `control` and `treatment`: rejected
  because it would discard the row/fold correspondence that distinguishes
  this path from the existing independent two-sample test, defeating the
  purpose of a "paired" bootstrap.
- Deriving a bootstrap p-value (e.g. via the proportion of resampled
  differences crossing zero) in addition to the confidence interval:
  rejected because bootstrap-derived p-values from a difference
  distribution are a distinct, caller-visible statistical claim with their
  own assumptions; `DES-AIDS-068`/`DES-AIDS-069` scope this path to interval
  estimation only, and adding an implicit p-value risks being read as formal
  significance testing without that claim being validated.
- Always using uniform (non-stratified) resampling regardless of `y_true`:
  rejected because for small or imbalanced classes, uniform resampling can
  produce bootstrap samples lacking one of the classes entirely, making
  class-dependent metrics such as ROC AUC undefined for that iteration.

## Consequences / 結果
This bootstrap path does not remove any cross-fold or cross-model dependence
already present in fold-level CV scores supplied by the caller; the reported
interval reflects only resampling variability of the supplied values, which
is disclosed in `DES-AIDS-068`'s constraints. Any future bootstrap-based
comparison path added to this module should reuse the shared-index
resampling pattern established here unless a new ADR documents a deliberate
departure.
