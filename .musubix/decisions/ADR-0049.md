# ADR-0049: Ghose and Egan as additional fixed-threshold drug-likeness rules

## Context / 背景
REQ-ACHEM-060 extends the existing Lipinski/Veber drug-likeness screening (REQ-ACHEM-020) with two more widely used fixed-threshold filters, Ghose and Egan, without re-reporting the Lipinski/Veber outcomes already covered.

## Decision / 決定
Evaluate the Ghose criteria (`MolWt`, `MolLogP`, `MolMR`, `heavy_atom_count`) and Egan criteria (`TPSA`, `MolLogP`) in two fixed, independently documented check orders, reporting only `ghose_violations`/`ghose_pass` and `egan_violations`/`egan_pass`, reusing descriptors already computed by DES-ACHEM-010 where they overlap (e.g. `MolWt`, `MolLogP`, `TPSA`).

## Rejected alternatives / 却下した代替案
Merging Ghose/Egan results into REQ-ACHEM-020's existing Lipinski/Veber output shape instead of a new method: rejected because REQ-ACHEM-020's acceptance criteria are already fixed and scoped to Lipinski/Veber only; adding fields to that existing result would be an undocumented behavior change for existing callers, whereas a new method keeps both independently stable.

## Consequences / 結果
Any future additional drug-likeness filter (e.g. Veber variants) should follow this same pattern: a new method with its own fixed check order, rather than silently growing an existing result shape.
