# ADR-0012: Opt-in, metadata-driven visual-readability audit (no OCR/imaging dependency)

## Context / 背景
REQ-AIDS-053 requires auditing rendered charts for readability issues
(missing glyphs, overlapping/missing labels) without regressing the
existing, default-off notebook audit contract (DES-AIDS-033) and without
adding a heavyweight dependency.

## Decision / 決定
DES-AIDS-041 extends `notebook_audit` with an opt-in
`audit_visual_outputs` phase, invoked only when `audit_notebook(...,
visual_audit=True)` is requested. It reads chart-authoring metadata that a
caller (e.g. `visualization.record_chart`) may attach to a cell's
`metadata["chart"]`, plus a lightweight PNG-header-based near-empty-image
heuristic, instead of re-rendering or OCR-scanning the image.

## Rejected alternatives / 却下した代替案
- OCR-based or pixel-level glyph detection: rejected as an unnecessary
  heavyweight dependency (no OCR/imaging library is currently used) for a
  problem the issue's own "Implementation options" already identifies as
  solvable by recording chart semantics at creation time.
- Making the visual audit phase mandatory/default-on: rejected because no
  current caller yet populates `metadata["chart"]`; making it mandatory
  would make every existing chart-bearing notebook fail audit by default,
  which is explicitly not the intended behavior until callers are updated.

## Consequences / 結果
Until `visualization.record_chart` (or another caller) is updated to
populate `metadata["chart"]`, every audited chart cell surfaces as
"unaudited" (informational, non-blocking) rather than a false "pass". The
existing default-off `audit_notebook` contract (DES-AIDS-033) is
unchanged.
