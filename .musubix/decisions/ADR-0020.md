# ADR-0020: Fixed L=20 Ising lattice with explicit seed/initial-state fixture for classical Monte Carlo

## Context / 背景
REQ-AIMS-030 requires a deterministically testable classical Monte Carlo
module. An early draft referenced "a fixed seed" without stating its
value or the lattice's initial spin configuration, which rubber-duck
review flagged as insufficient for a fully repeatable TDD fixture.

## Decision / 決定
DES-AIMS-030 fixes the reference acceptance fixture to an L=20 periodic
square Ising lattice, J=kB=1, random seed 12345, and an all-spins-up (+1)
initial configuration, with 2000 equilibration sweeps discarded before
8000 sampling sweeps are averaged. The Onsager critical temperature
T_c = 2.269185 (J/kB) is used as the reference boundary between the
ordered (T=1.5) and disordered (T=3.5) regimes.

## Rejected alternatives / 却下した代替案
- Leaving the seed/initial configuration unspecified and only constraining
  statistical behavior: rejected because two conforming implementations
  with different (unspecified) seeds could pass or fail the acceptance
  thresholds by chance, especially near the transition; fixing the exact
  seed and initial state removes that nondeterminism from the test.
- A random/disordered initial configuration: rejected in favor of the
  simpler, fully reproducible all-spins-up state, since the equilibration
  sweep count is generous enough to reach the sampling regime regardless
  of starting configuration.

## Consequences / 結果
The acceptance fixture's magnetization thresholds (>0.8 / <0.2) are tied
to this specific seed and initial state; changing either would require
re-deriving and re-validating the thresholds.
