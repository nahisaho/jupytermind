# ADR-0048: Symmetric boolean Cα contact matrix with a sequence-separation floor

## Context / 背景
REQ-ASTRUCT-050 needs a deterministic residue contact-map heuristic, explicitly scoped as a Cα-only heuristic, not an atom-level, side-chain-aware, or solvent-aware contact model.

## Decision / 決定
Evaluate `contact[i][j]` as true iff `|i-j| >= min_sequence_separation` and the Euclidean distance between coordinates `i` and `j` is at most `distance_threshold_A`, with `contact[i][i]` always false, the matrix always symmetric, and `total_contacts` counted only over the upper triangle `i < j` to avoid double-counting.

## Rejected alternatives / 却下した代替案
Using full-atom coordinates or inferring side-chain orientation: rejected as out of scope for this increment, which only accepts a single coordinate per residue (implicitly Cα); the module is documented as a Cα-only heuristic rather than silently implying atom-level accuracy.

## Consequences / 結果
A future requirement for atom-level or side-chain-aware contact detection would need its own requirement and a richer input schema, not a silent extension of this module's single-coordinate-per-residue contract.
