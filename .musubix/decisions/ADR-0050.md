# ADR-0050: Small fixed named-SMARTS alert list, not a PAINS/Brenk reimplementation

## Context / 背景
REQ-ACHEM-070 needs a deterministic structural-alert screen with no external filter catalog dependency and no network call, while being clear it does not claim PAINS/Brenk-catalog completeness.

## Decision / 決定
Compile and match exactly 5 fixed named SMARTS patterns (`nitro_group`, `aldehyde`, `michael_acceptor_enone`, `epoxide`, `free_thiol`) in a fixed alert-definition order, reporting only matched names in that order plus `alert_count`, and disclose the heuristic's limitation verbatim via the fixed bilingual label.

## Rejected alternatives / 却下した代替案
Vendoring a full PAINS or Brenk SMARTS catalog (hundreds of patterns): rejected as disproportionate scope for this increment and a potential licensing/maintenance burden; the small fixed list is instead explicitly disclosed as illustrative, not a validated PAINS/Brenk filter catalog, in both the design and SKILL.md.

## Consequences / 結果
Any future requirement for broader structural-alert coverage would need a new requirement defining which catalog subset to bundle and how to keep it current, not a silent expansion of this fixed 5-pattern list.
