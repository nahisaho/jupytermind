# ADR-0107: Simplified median-of-ratios + Welch's t-test differential expression, not a full DESeq2/edgeR negative-binomial GLM

## Context / 背景
REQ-AGENOM-060 adds a differential-expression heuristic module to
`ai-genomics-scientist`. Real RNA-seq differential-expression tools
(DESeq2, edgeR, limma-voom) fit a negative-binomial generalized linear
model per gene, with shrinkage estimation of per-gene dispersion across
the whole dataset, often via iterative numerical optimization and
external R-package-only algorithms with no pure-Python/numpy/scipy
equivalent available in this repository's dependency set. This skill's
established architecture (consistent with `ai-chemistry-scientist`'s
ADR-0025 no-network/no-external-binary constraint, and
`ai-genomics-scientist`'s own existing heuristic modules such as
DES-AGENOM-030's fixed-PFM splice-site scorer) commits to pure
numpy/scipy implementations with no R interop, no external statistical
packages, and explicit, auditable heuristic-limitation documentation
wherever a simplification departs from a published gold-standard
method.

## Decision / 決定
Implement exactly the normalization and testing pipeline that
REQ-AGENOM-060's Statement defines: DESeq2-style median-of-ratios size
factors (geometric-mean-per-gene reference, per-sample median ratio,
computed with pure numpy), per-gene size-factor normalization, Welch's
two-sample t-test (`scipy.stats.ttest_ind(..., equal_var=False)`) on
`log2(normalized_count + 1)` values between exactly 2 groups, and
Benjamini-Hochberg `padj` across all genes in the run (pure numpy, no
`statsmodels` dependency). Degenerate zero-variance genes (constant
`log2(normalized_count + 1)` within both groups) are defined to report
`p_value = 1.0` rather than `NaN`, as a deliberate deterministic
heuristic convention for this specific degenerate category — not a
general claim that every such case establishes no difference between
groups (two constant groups can still have different means) — because
scipy's t-test on exactly zero pooled variance produces `NaN`/`inf`,
which this module never surfaces in a result.

## Rejected alternatives / 却下した代替案
Implementing a true negative-binomial GLM with dispersion shrinkage
(replicating DESeq2's actual per-gene model): rejected — this requires
either an R interop bridge (violates the no-external-binary
architecture) or a from-scratch pure-Python negative-binomial MLE with
empirical-Bayes dispersion shrinkage, which is a research-grade
reimplementation effort far beyond this module's heuristic scope and
would risk silently diverging from the real DESeq2 algorithm it claims
to resemble, creating a false sense of equivalence.
Adding `statsmodels` as a dependency for its built-in Benjamini-Hochberg
helper: rejected — the BH procedure is a short, well-defined
rank-based correction implementable in a few lines of pure numpy, so
adding a new third-party dependency purely for this one helper is not
justified.
Propagating scipy's native `NaN` for zero-variance genes: rejected as
a silent footgun — a caller filtering or sorting by `p_value`/`padj`
would either crash or silently misorder results; explicitly defining
`p_value = 1.0` for the "no detectable difference" case keeps the
module's output always JSON-safe and sortable, matching
REQ-AGENOM-004's requirement that every module's run result be
JSON-safe.

## Consequences / 結果
This module's results are a heuristic, not a drop-in DESeq2 replacement.
REQ-AGENOM-060 itself already requires that the module not be
represented as a full DESeq2/pyDESeq2-style method; documenting this
limitation in `SKILL.md` (mirroring DES-AGENOM-030's existing
heuristic-label pattern) is this ADR's selected implementation approach
for satisfying that existing constraint, not a new mandatory
deliverable beyond what REQ-AGENOM-060 already requires. Any future
upgrade toward a true negative-binomial model would be a breaking
change to this module's statistical method (though not necessarily to
its `{gene_id, base_mean, log2_fold_change, p_value, padj}` output
shape) and must be tracked as a new ADR superseding this one.
