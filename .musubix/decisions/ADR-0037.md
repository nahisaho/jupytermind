# ADR-0037: Standard genetic code codon translation for variant-effect classification

## Context / 背景
REQ-AGENOM-020 needs a deterministic 4-way classification (synonymous/missense/nonsense/readthrough) of a single-base codon substitution.

## Decision / 決定
Translate both the reference and alternate codon using the standard genetic code (NCBI translation table 1) and classify strictly from the same-vs-different amino acid and stop-codon status of each side, with no alternative genetic code table supported in this increment.

## Rejected alternatives / 却下した代替案
Supporting alternative genetic codes (e.g. the mitochondrial code, NCBI table 2): rejected as out of scope for this requirement, which only specifies the standard code; introducing a table-selection parameter would add an unrequested axis of configuration with no acceptance criteria to validate it against.

## Consequences / 結果
A future requirement for organism-specific genetic codes would need its own table-selection parameter and acceptance criteria, layered on top of this module rather than silently branching it.
