# ADR-0070: Gate correlation interpretation on a caller-configurable significance threshold, with a distinct non-significant template

## Context / 背景
`DES-AIDS-051` (REQ-AIDS-063, GitHub #37) addresses `correlation`'s
interpretation text ignoring statistical significance: it currently
always emits a strength/direction phrase (e.g. "a moderate positive
correlation") purely from `r`'s magnitude and sign, even when the
associated p-value gives no statistical basis to claim a real
relationship exists, which can mislead a reader into over-trusting a
noise-driven correlation.

## Decision / 決定
Add a `significance_threshold: float = 0.05` parameter to `correlation`,
threaded into `_interpret`. When `p_value >= significance_threshold`,
`_interpret` returns a sentence template textually distinct from (not a
weakened variant of) the existing strength/direction wording — reporting
the computed `r` and p-value display but explicitly stating "no
statistically clear correlation is observed" instead of a
magnitude/direction claim. When `p_value < significance_threshold`, the
existing wording path is unchanged. Values outside `[0.0, 1.0]` raise
`ValueError` before any interpretation is computed.

## Rejected alternatives / 却下した代替案
- **Hard-coding the significance check at a fixed `0.05` threshold with no
  parameter**: rejected — different analyses legitimately use different
  significance conventions (e.g. `0.01` for stricter domains); a
  caller-configurable parameter with a conventional default satisfies
  both the common case and domain-specific needs without a breaking
  change (the parameter is additive and optional).
- **Softening the existing strength/direction wording for
  non-significant results (e.g. prefixing "possibly") instead of a fully
  distinct template**: rejected per REQ-AIDS-063's explicit requirement
  that the non-significant sentence be textually distinct, not a
  weakened variant — a softened version remains easy to misread as "a
  weak but real correlation," which defeats the purpose of flagging
  non-significance.
- **Suppressing/omitting the interpretation sentence entirely for
  non-significant results**: rejected — silence would remove useful
  information (the computed `r` and p-value are still meaningful data
  points) and would be a more disruptive, less backward-compatible
  change than adding a clearly labeled alternative sentence.

## Consequences / 結果
Any future addition to `correlation`'s interpretation logic must
preserve the "distinct template, not a weakened variant" invariant for
the non-significant case, and must continue computing `p_display`
identically in both branches (ADR-0072) so the two sentences never
disagree on the reported p-value. Covered by the REQ-AIDS-063 acceptance
tests in `tests/test_stats_analysis.py`.
