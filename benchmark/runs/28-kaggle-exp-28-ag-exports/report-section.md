2011年の当該CSVでは、中西部が総輸出額の48.10%で最大でした。掲載9品目では果物、トウモロコシ、小麦が上位ですが、掲載部分は総額の55.06%にすぎません。未掲載部分の内容が不明なため、全農産物の品目順位・完全な内訳には一般化できません。

3回の反復によって、掲載品目のみを分母にすると西部・南部の順位が逆転すること、果物の西部集中の強さはCaliforniaに大きく依存すること、生鮮・加工区分に独立した地域差の情報が乏しいことが確認されました。AIの追加分析は、単に手法を増やすのではなく、初回結論の分母・集中の意味・データ定義を狭める役割を果たしました。丸めへの安定性と、州除外への安定性も分けて評価しています。

追加依頼は最大3回に到達しました。同じCSVで計算を増やしても、未掲載内容や正式定義、Kaggle版との同一性は解消できないため、AIは反復を終了しています。3回とも `initial.log` が記録する初回実行中に完了しており、外部の `followup.log` は既存履歴を保持して上限を超える依頼を追加しないと判断しています。外部の追加確認と、Notebook内の3回の分析反復を同一視しません。

### 発生した問題とJupytermind改善候補

分析全体の未完了や最終エラーセルは確認されませんでしたが、取得・描画・監査には次の問題と留保があります。

**外部の取得・統合経路**: Kaggle SDKで `dataset_list(page_size=...)` を指定した際の `TypeError` は、Notebookの互換性メモで報告され、標準の `dataset_list(search=...)` に修正されています。空白を `%20` に変換したダウンロード保存名も、取得コードが両方の名前を確認することで対応しています。いずれもSDK・呼出側の問題として切り分けます。最終的なフォールバック理由は取得CSVのスキーマ不一致であり、Kaggle認証失敗ではありません。

実行中Notebookの自己書換えとMCP保存の競合は、Notebookの実行方式説明で統合経路の制約として記録されています。別の制御Notebookによる直列書込みで回避していますが、今回の指定証拠では新たな競合障害を再現していません。Copilot CLI・外部ランナー固有の障害も確認されておらず、正常な成果物確認後の停止をJupytermindの不具合候補には含めません。

**候補1 — 定義不確実性の列挙範囲**: `module-diagnostics` で、単位だけが `inferred` のmanifestを `build_manifest` で作り、`unresolved_fields()` を呼ぶと、列挙数は0でした。推定単位を未解決一覧だけで確認すると見落とす可能性があります。ただしNotebookは同関数のdocstringがunknownのみを対象とすると報告しており、実装単独のバグとは断定しません。候補は、不確実性一覧の対象を明示するAPI・文書改善、または推定項目も選択的に列挙する機能です。今回の回避策は、全 `FieldValue` を走査し、`unknown` と `inferred` を両方出力することでした。

**候補2 — 棒グラフのラベル切れ**: Notebookの改善候補節は、10×5インチ・長い日本語品目名の棒グラフで、`figure.autolayout` が無効の初回PNGに品目名下端と横軸名の切れがあったと報告しています。欠落グリフが0でも、品目や分母の説明が読めない影響があります。`figure.autolayout=True` にして再描画した最終PNGは、抽出画像でもラベルが収まっています。初回PNGそのものは今回の指定証拠に含まれないため、修正前の現象はNotebook内の報告として扱い、独立に再確認したとは記述しません。

**候補3 — 図表メタデータ欠落の検出不足**: `module-diagnostics` は実PNG出力付きの図表セルをコピーし、`metadata.chart` を除いて `audit_visual_outputs` を呼んでいます。出力は `chart_without_metadata_visual_findings=[]` でした。監査合格だけでは、ラベル・欠落グリフに必要な情報が存在し、検査されたことを保証できません。今回はタイトル・軸・凡例・グリフ情報をセルに付与し、最終監査前にメタデータの存在と画像ハッシュを別途assertしています。

3件は `issue-candidate.json` に分類、再現手順、期待・実際の挙動、影響、指定証拠内の根拠、受け入れ条件を保存しています。ライブラリの修正やGitHub Issue登録を実施したという意味ではありません。
